Website resmi untuk **Divisi Advokasi dan Kesejahteraan Mahasiswa (Advokesma) BEM FAKSAS Universitas Abdurachman Saleh Situbondo**. 

Proyek ini dibangun untuk memperkuat *branding* divisi, memfasilitasi komunikasi dengan mahasiswa, dan menyediakan portal pengaduan yang terintegrasi langsung dengan WhatsApp guna memenuhi program kerja (proker) BEM.

## ✨ Fitur Utama

* **Responsive Design**: Antarmuka yang dioptimalkan untuk berbagai ukuran layar (Desktop, Tablet, dan *Mobile*) menggunakan Tailwind CSS.
* **Formulir Pengaduan Terintegrasi**: Memungkinkan mahasiswa untuk mengirimkan keluhan atau aspirasi yang langsung diteruskan ke WhatsApp Admin Advokesma dengan format pesan yang sudah terstruktur (*WhatsApp API wa.me*).
* **Modern UI/UX**: Menggunakan skema warna profesional (Navy & Kuning), tipografi dari Google Fonts (Inter), dan ikonografi dari FontAwesome.
* **Smooth Scrolling & Transitions**: Memberikan pengalaman navigasi yang nyaman dan interaktif antar sesi halaman.
* **Mobile Navigation Menu**: Hamburger menu yang intuitif untuk kemudahan akses di perangkat *mobile*.

## 🛠️ Teknologi yang Digunakan

* **Markup**: HTML5
* **Styling**: Tailwind CSS (via CDN)
* **Interactivity**: Vanilla JavaScript
* **Assets**: Google Fonts (Inter), FontAwesome 6.4.0

Karena proyek ini adalah *static website* murni, kamu tidak perlu menginstal *dependency* atau *package manager* seperti npm. 

1. **Clone repositori ini:**
   ```bash
   git clone [https://github.com/username-kamu/nama-repo-kamu.git](https://github.com/username-kamu/nama-repo-kamu.git)

2. **Buka Folder Project**
   ```bash
   cd BEM-ADVOKESMA-UNARS

3. **Jalankan Di Browser**
   Kamu bisa langsung membuka file index.html di browser pilihanmu. Untuk pengalaman development terbaik, sangat disarankan menggunakan ekstensi Live Server di VS Code.
